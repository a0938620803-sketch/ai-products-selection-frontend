# AI 智慧商品選品系統前端

（一兩句話說明：這個前端給誰用、提供哪些畫面或功能，例如商品熱度儀表板、風險示警等）

## 技術棧
- Angular 21（Angular CLI 21.2.21）
- TypeScript
- Vitest（單元測試）

## 本機啟動

先確認後端已啟動，再執行：

​```bash
npm install
ng serve
​```

啟動後開啟 `http://localhost:4200/`，修改程式碼會自動重新載入。

## 其他指令

​```bash
ng build   # 建置，產出在 dist/
ng test    # 執行 Vitest 單元測試
​```
